# 学校の校務自動化 GAS入門　サンプルファイル

サンプルファイルのダウンロード.
緑の「Code」ボタン →「Download ZIP」

書籍『生成AIと作る、学校の校務自動化 GAS入門』（第1巻〜第3巻）に載せているコード（Google Apps Script）と、練習用の架空名簿です。

| フォルダ | 内容 |
|---|---|
| `vol1` | 第1巻　名簿・席替え編（共通部品、並べ替え、メニュー、年度更新、席替え、班づくり、クラス分け、座席表の整形） |
| `vol2` | 第2巻　フォーム連携・書類メール編（フォームの回答、提出状況、リマインド、出欠、アンケート、係決め、面談、お便り・賞状、PDF、一斉メール、カレンダー） |
| `vol3` | 第3巻　定期実行・Webアプリ編（自動実行、当番、締切の通知、今日のボード、Webアプリ、予約表、バックアップ、引き継ぎ ほか） |

各フォルダの `README.txt` に、使い方があります。`sample_roster.csv` は架空の名簿です。実在の児童生徒・保護者とは関係がありません（メールアドレスは、実在しない宛先 `example.invalid` です）。

## 使う前に

- **本物の名簿や、実在の保護者のメールアドレスで、いきなり動かさないでください。** まず、新しいスプレッドシートと、架空名簿で試してください。
- 学校のGoogleアカウントでは、管理者の設定で、Apps Script・フォーム・メール・Webアプリなどが使えない場合があります。
- コードは、スプレッドシート・メール・ドライブ・カレンダー・Webアプリの動きをまねた、検証用の環境で、自動テストしてあります。Googleの画面やサービスの更新で、動かなくなることがあります。自己責任でお使いください。
- 生成AIに相談するときは、本物の個人情報を入力しないでください（書籍の第1巻、第2章）。
